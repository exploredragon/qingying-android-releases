# WeThin Android

这里托管 WeThin（原轻盈日记）安卓测试版安装包和更新清单，源码位于私有仓库。

[下载最新版本](https://github.com/exploredragon/qingying-android-releases/releases/latest)

安装后在「我的 → 关于」检查更新。新版下载后由系统确认安装，覆盖升级保留已有记录与草稿。首次可能需要允许应用安装 APK。

- APK：完整安装包。
- update.json：版本、下载地址、大小与 SHA-256，供客户端自动检查。
- SHA256SUMS.txt：安装包校验值。

当前为测试版，不提供差分包。使用同一包名和签名覆盖安装；不要先卸载旧版。

在「我的 → 外观」可选择明暗模式、主题色、字号、照片墙列数与样式，设置即时生效并保留。


0.6.0 起在「今日 / 我的 → 饮食回顾」查看周报、月报和自选日期报告，支持匿名PNG长图。首次确认报告设置后启用自动生成，报告提醒可单独开启。后台调度可能受系统和网络影响。

0.7.0 起报告结合实际菜品给出饮食观察和下一餐建议。打开应用或返回前台时后台检查更新，新版弹窗支持升级、忽略及“忽略这个版本”；后续新版仍提醒，关于页可随时手动检查。

0.7.1 修复识别状态卡住的问题。服务端独立处理任务，退出应用后仍会回收结果；圈子中未完成识别自动刷新。后台兜底工作流每5分钟检查任务，日志仅包含处理数量和状态。
